# Training App

A mobile-first training application built with React, Ionic, and Supabase.

## Tech Stack

- React
- Ionic
- TypeScript
- Supabase
- Vite

## Features

- User authentication
- Supports hungarian and english language
- Forum
- Direct messages
- Basic food recognizer with Mobilenet
- Workout and diet generator
- Usable on mobile and PC
- Supabase database and authentication
